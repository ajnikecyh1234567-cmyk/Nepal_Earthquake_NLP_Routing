## BERT model weights

The fine-tuned BERT weight file
`python_nlp/bert_results/bert_model/model.safetensors`
is not included in this repository because it exceeds GitHub's
100 MB file-size limit.

The model can be regenerated by running:

`python_nlp/train_bert_classifier.py`

The prediction outputs and evaluation results used in the dissertation
are included in `python_nlp/bert_results/`.
